## 3. 已实现功能与用户确认的设计

- 六个主页面：交易图表、监控面板、账户总览、交易记录、回放模拟、复制交易。
- 监控面板：有持仓的实盘账户各一张卡片（余额、实时浮动盈亏、K 线图 + 持仓 / 止盈止损线）；3 秒轮询两桥全部账户，每张卡片一条 SSE；不经 tradingRouter，回放期间仍显示实盘；隐藏账户偏好不影响本页；完全只读，不画未成交 bracket 预览线。
- 桌面支持多标的 1 / 2 / 4 图。“交易面板”和“账户信息”从右上角独立呼出，**在右侧左右并排**。
- 侧栏持仓 / 订单覆盖**当前账户的所有合约**，不只当前图表，也不是跨全部账户聚合。
- 隐藏账户在侧栏灰化保留恢复入口，交易下拉不显示；不因部分账户离线、快照缺项或刷新而自动恢复。账户总览仍列出全部当前账户。
- 账户总览按连接分组，无账户选择器，卡片 / 列表切换，美元显示 USD。
- 交易记录从两桥磁盘归档同步到浏览器。先完整 FIFO 配对再筛选，显示入场价 / 离场价 / 盈亏；无手续费列但净盈亏会计入可取得的费用；统计在上方，支持组 / 账户 / 合约 / 日期。
- 点击交易打开独立详情图，懒加载失败有局部提示，不使终端黑屏。
- 搜索栏可拖动、收藏；NT8 候选由原生换月规则返回当前合约。已有旧月图表及精确历史解析保留原合约。
- 附加 TP/SL 随净持仓数量同步；未成交父单显示保护预览虚线；实际工作单可在图上拖改 / 删除撤单。
- 图上成交为小箭头：买绿正上、卖红正下、尖端贴成交点、无文字；切周期按原始时间重建。
- 原生图表布局本地保存；当前运行库 v32.1.0，旧 v29.4 副本只作历史留存。
- 回放为独立 dashboard，可新建、继续、删除 session，保存独立资金、订单、成交和表现统计。
- 手机不显示多图；导航折叠菜单，图表和紧凑面板上下共存、可拖高度。保持电脑布局和偏好。
- NT8 与 ATAS 账户统一管理，按平台 / 连接分组；连接状态分别显示。
- 复制服务独立运行，能跟随主账户在网页、NT8、ATAS 中产生的新实际成交，浏览器关闭后仍运行。

## 4. 最近修复：后续最容易回归的地方

### 2026-09-14：ATAS SSE 断连误报

- 本次只读现场检查：ATAS `8.0.15.643`，已加载桥版本 4，`connected=true`，`error/tradingError` 为空；`marketError` 为 `Unable to write data to the transport connection: 你的主机中的软件中止了一个已建立的连接。.`。
- 根因：`AtasMarketService.StreamAsync` 把向浏览器 SSE 写入时的连接异常捕获为全局行情错误。现在数据帧与心跳共用写入边界，将下游传输异常转换为该订阅取消；历史、行情源及队列错误不做此转换。源码桥版本升为 5。
- 已运行 `atas-bridge/build.cmd -AtasPath "D:\Program Files\ATAS X" -Test`，构建 0 警告 / 0 错误，HTTP、market、trading 模拟测试通过。新增覆盖数据帧 / 心跳的 write / flush 断连、正常 SSE 帧、非传输异常及取消。
- 构建产物为 `atas-bridge/dist/TvAtasBridge.dll`；已备份旧安装副本到 `.tmp-webbridge/atas-sse-fix-20260914-150308/TvAtasBridge.dll`，并更新 `%APPDATA%\ATAS X\Indicators\TvAtasBridge.dll`，安装与构建 DLL 的 SHA256 一致。ATAS 已热加载，实测 `/api/status` 返回 `bridgeVersion=5`、`connected=true`，`error/marketError/tradingError` 均为空。
- 现场只读回归：从原生目录选取 `#MNQU6@CME`，独立 SSE 客户端收到实际行情帧后主动 TCP reset；等待超过一次 10 秒心跳后，状态仍为已连接且无行情错误。未重启平台，未进行真实账户交易操作。

### ATAS 仓位线

用户图表标题为 `Micro E-mini Nasdaq-100 · 1 · CME_Ind`，实际是连续合约；真实持仓使用月份合约完整 ID。修复链路：

2. `lib/chartInstrument.ts` 比较完整 ID，忽略绘图库造成的大小写差异；不截断 ID、不猜测延迟源或其他月份。

4. `useOrderLines` 在账户或合约变化时清理并重建图形，因为库能返回旧合约中已隐藏的 shape。旧账户事件、迟到 Promise 不得触发交易或复活旧线。

### 隐藏账户自动恢复

已删除 `ChartTerminal` 的 `pruneHiddenAccounts`：同桥部分账户暂缺不能证明账户已永久删除。`nt8-terminal-hidden-accounts` 只通过眼睛按钮变更。测试覆盖暂缺 → 返回 → 刷新 → 手动恢复；已被旧代码清掉的偏好不能凭空恢复，用户需再隐藏一次。
