# ATAS X 数据与交易桥

本桥将已经登录 ATAS X 的账户、持仓、订单、成交和行情接入现有网页终端。已适配 **ATAS X 8.0.14.646、8.0.15.643 beta / .NET 10**，复用 ATAS 的现有连接，不需要向网页填写 TradersLaunch 或 dxFeed 密码。

## 编译与加载

需要 .NET 10 **SDK** 及完整 ATAS X 安装目录。在项目根目录的 PowerShell 中运行：

```powershell
.\atas-bridge\build.cmd -AtasPath "D:\Program Files\ATAS X" -Test
```

可加载产物：`atas-bridge/dist/TvAtasBridge.dll`。编译中间产物位于 `.build-check/`，无需复制 ATAS 自带的 DLL。

1. ATAS X 保持账户连接，在指标窗口选择 **Add custom indicator / 添加自定义指标**，载入上述 DLL。
2. 在任意一个图表添加 **TradingView Terminal Bridge** 指标，并保留该图表。指标不绘制曲线，也不改变 ATAS 图表的账户选择。
3. 打开或刷新网页。右上角分别显示 `NT8 已连接/未连接` 与 `ATAS 已连接/未连接`。账户总览、账户信息、交易面板列出两边账户，按 `NT8 · 连接名`、`ATAS · 连接名` 分组。

同一 ATAS 进程的多个桥接指标共享一个监听端口。移除全部桥接指标或关闭 ATAS，会停止桥接服务。桥加载本身不会创建入场订单。

替换 DLL 时，新桥会等待旧桥停止交易同步并完成归档后接管端口。热更新期间端口暂被占用会自动重试，移除指标会取消等待；无需为了释放桥端口重启 ATAS。

## 网页账户与行情

两桥独立运行：NT8 使用 `127.0.0.1:8090`，ATAS 使用 `127.0.0.1:8091`。手机或其他电脑经前端服务器同源代理访问，分别为 `/api/*` 和 `/atas/api/*`。无需把桥端口暴露到局域网。

两边同名账户以来源区分，交易请求按所选账户路由。选择另一来源的账户时，图表切换到对应行情源；切换完成前暂停入场操作，避免把一个平台的合约名直接提交到另一个平台。各平台保留自己的原生合约标识，图表布局与合约收藏按行情源保存。已有 NT8 账户选择及成交归档会迁移到统一账户标识。

持仓与工作订单从全局连接读取，覆盖该账户的所有合约。交易记录统一展示两桥归档，可按账户组、账户、合约和日期筛选；交易详情使用该笔成交对应的行情源。

## 交易与本地归档

支持市价、限价、止损、止损限价委托，以及撤单、改价、按合约平仓。桥创建的附加止盈止损在入场成交后挂出，数量跟随该账户同合约的净持仓。尚未成交的入场单通过 `/api/brackets` 提供保护价预览。每个账户同合约仅保留一组桥管理的保护，加减仓时可以沿用原组。

同时附加 TP 和 SL 要求对应 ATAS 连接支持服务器 OCO；不支持时会在提交入场前返回原因。桥不会自动重发结果不明确的入场委托。移除指标时不撤销已经提交到平台的工作单；桥停止期间，后续入场成交的附加单生成及持仓数量同步也会停止。

普通入场、撤单或改单被上游拒绝时，交易面板显示该次请求的原始原因，不把历史拒单长期当作保护故障。状态栏的保护异常只反映当前尚未解除的保护/同步问题；账户面板只显示本账户的保护错误。真实保护单被拒或结果不明时仍会保留错误，关闭保护计划后清除已解除的提示。成交归档的 `warning` 仅用于归档本身的问题。

数据保存于 `%LOCALAPPDATA%\TradingViewTerminal\ATAS\`：

| 文件 | 内容 |
|---|---|
| `executions.jsonl` | 逐笔成交，保留原始毫秒时间、账户、合约、方向、价格、数量及可取得的点值 |
| `protections.json` | 桥创建的保护计划及订单标识，用于重启核实 |
| `bridge-errors.log` | 桥初始化错误 |

挂载时导入 ATAS 当前仍可查询的成交，运行时持续记录新成交。ATAS 已经丢失、且此前未被桥归档的历史成交无法凭空补回。网页 IndexedDB 保存统一查询缓存，桥端 JSONL 独立于浏览器存在。归档写入失败会显示错误，并保留待写记录。

## 实现与排障

`AtasPlatformAccess` 使用本机版本提供的公共服务定位入口 `OFT.Plarform.Core.Extensions.ResolveExtension` 取得全局连接、合约和历史服务。这里的 `Plarform` 是 ATAS 程序集的实际拼写。由于平台接口随 beta 版本变化，入口会核对安装版本，版本不匹配时明确报告错误。

历史行情通过 ATAS 原生缓存/行情提供者请求，保留交易所时区和交易时段；实时数据通过共享合约行情事件及 ATAS 原生 K 线构建器处理。多标的订阅彼此独立，缺失行情不会用平盘 K 线填充。

在运行 ATAS 的电脑访问 `http://127.0.0.1:8091/api/status` 可查看连接、版本、归档和错误信息。无法访问时先检查指标是否已添加以及端口是否被其他进程占用。版本/服务初始化错误会写入上述错误日志，修复后重新挂载指标。

`version` 始终报告当前实际加载的 ATAS 版本，`supportedVersions` 列出已验证版本；初始化失败也不会回退显示旧版本号。ATAS 更新后若出现“服务异常”，先查看这里的 `error`。桥版本 2 已修复升级到 8.0.15.643 后被旧单版本检查拦截的问题，构建测试也会执行真实 SDK 的启动版本检查。

自动测试只使用独立临时目录和模拟连接，不向正在运行的 NT8/ATAS 发送交易操作。真实账户回报和 dxFeed 历史数据权限需要在加载指标后确认。
